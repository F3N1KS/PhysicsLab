# PhysicsLab

Интерактивная физическая лаборатория на русском языке: React 19, TypeScript, Vite, SVG и Recharts. Все вычисления выполняются в браузере. Бэкенд, аккаунт, база данных и API-ключи не нужны. Шрифты поставляются локально с приложением.

## Быстрый запуск

Требуется Node.js 22.12+ (проверено на 24.22.1), npm 10+.

```sh
npm install
npm run dev
```

Vite выведет локальный адрес. Для production:

```sh
npm run build
npm run preview
```

При размещении на хостинге настройте fallback всех маршрутов на `index.html` (SPA). Содержимое `dist/` можно обслуживать любым статическим сервером.

## Проверки

```sh
npm run test
npm run build
npm run test:e2e
```

`test` запускает тесты физического ядра, парсера, камеры и координатных делений в Vitest. Playwright автоматически поднимает Vite и по умолчанию использует свой Chromium на Linux, Windows и macOS:

```sh
npx playwright install chromium
npm run test:e2e
```

Для системного Chromium можно переопределить путь переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` (в облачной среде `/usr/bin/chromium`). На Windows, например: `$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH="C:\path\chrome.exe"` в PowerShell. Без переменной Linux-путь не подставляется. `.npmrc` помещает кэш npm в игнорируемый каталог проекта: установка работает и в средах с недоступным домашним каталогом.

Браузерные проверки охватывают страницы и навигацию, физические параметры, запуск/паузу/перемотку/шаги, три режима, слои, снимок, перемещение начальной точки и вектора, размеры и скрытие панелей, графики, сравнение, CSV/SVG, ошибки редактора. Проверяются ширины 375/768/1440/1920 px в двух темах. Снимки сохраняются в `test-results/` и не входят в Git.

## Возможности

- Главная с научной SVG-визуализацией, каталог механики с поиском и тематическими фильтрами. Будущие эксперименты явно отмечены; остальные разделы содержат страницы о будущей реализации.
- Бросок под углом, вертикальный и горизонтальный бросок как начальные условия общей модели. Гравитация Земли, Луны, Марса; масса, высота, начальная координата, линейное сопротивление, ветер.
- Точные поля и ползунки; индивидуальные границы и шаг в пределах безопасного диапазона. Точный ввод независим от шага ползунка, сохраняет промежуточный текст и объясняет ошибки. Удобные исходные диапазоны, пользовательские границы и абсолютные пределы разделены.
- Одинаковый физический масштаб осей, перемещение камеры, масштабирование относительно курсора от 10⁻⁷ до 10⁷ px/м, вписывание траектории. Обычное колесо над сценой меняет только масштаб; панели передают прокрутку странице на своих границах. На паузе при t = 0 можно перетаскивать тело и конец начального вектора. Камера фиксируется при таком взаимодействии; кнопка «Вписать траекторию» восстанавливает автоподбор.
- Слои траектории, скорости, ускорения, тяжести, сопротивления, проекций, координат, характерных точек и равноотстоящих во времени отметок. Подсказка по нажатию на тело.
- Запуск, пауза, сброс, шаг ±0,05 с, временная шкала, скорости 0,25×–4×, цикл. Изменение параметров останавливает воспроизведение и возвращает t = 0.
- HUD текущих значений и отдельные характеристики полёта. Данные сцены, измерений и временного курсора графиков берутся из одного объекта `Flight`.
- До четырёх графиков с произвольными физическими осями, наведением, выбором времени, масштабированием и увеличением. Сравнение только наложением кривых, до шести сохранённых запусков; удаление и очистка.
- Таблица с шагом и выбором времени, экспорт CSV, экспорт каждого графика SVG, формулы и сведения о методе.
- Редактор сил Fx/Fy с пользовательскими константами, начальные условия в общей панели, шаг и горизонт RK4. Модель применяется только после проверки и успешного расчёта; ошибка оставляет предыдущую модель активной.
- Светлая и тёмная темы, адаптивные выдвижные панели, изменение ширины мышью и стрелками клавиатуры, разворот рабочей области. Тема хранится локально; один снимок модели, параметров, слоёв и времени — в `sessionStorage` текущей вкладки. При обновлении страницы снимок доступен для восстановления. Сравнения живут до выхода из лаборатории.
- Анимации учитывают `prefers-reduced-motion`. У графиков и лаборатории отдельные загружаемые модули.

    Brand.tsx         Векторный логотип
  pages/

Физическое ядро не зависит от React и пикселей. `Flight.at(t)` возвращает согласованное состояние; 601 отсчёт используется для графиков и визуализации. Для пользовательской модели сохраняются внутренние узлы RK4; промежуточное состояние уточняется RK4 от ближайшего узла, а не интегрируется заново от начала.

## Математика

Без сопротивления: `x = x0 + vx0*t`, `y = h0 + vy0*t - g*t²/2`. Масса влияет на энергию, но не на траекторию.

При линейном сопротивлении `F = -k(v-u)` используются точные решения. Если `b=k/m`, `a0` — начальное ускорение, то `v=v0+a0*q`, `r=r0+v0*t+a0*r`, где `q=(1-exp(-bt))/b`, `r=(t-q)/b`. Для малых `bt` применяются `expm1` и ряд Тейлора, для `k=0` — непрерывный предел. Вершина стандартной модели вычисляется аналитически.

Контакт с `y=0` останавливает движение, время уточняется бисекцией. Бросок с земли с горизонтальной/направленной вниз скоростью сразу считается приземлившимся. Энергия `Ek=mv²/2`, `Ep=mgy`; сопротивление рассеивает энергию, ветер может передавать её телу.

Пользовательские силы интерпретируются собственным Pratt-парсером: `+ - * / ^`, скобки, `sin cos tan sqrt abs exp log`, `pi e`; переменные `t x y vx vy m g k ux uy` и именованные числовые константы. Нет `eval`, `Function` или выполнения JavaScript. Пример:

```text
Fx = -k * (vx - ux)
Fy = -m * g - k * (vy - uy)
```

Силы делятся на массу, затем RK4 решает систему `(x', y', vx', vy') = (vx, vy, Fx/m, Fy/m)`.

## Ограничения первой версии

- Реализован один эксперимент и только 2D. Произвольные системы ОДУ и 3D пока отсутствуют.
- Линейное сопротивление не моделирует турбулентность и квадратичное сопротивление. Поверхность горизонтальна; отскоков нет.
- Стандартный расчёт ищет приземление с геометрическим расширением интервала до 1 000 000 с, без временного интегрирования. Пользовательский — 120 с, 20 000 шагов, `dt` от 0,001 до 0,1 с. Это фиксированный RK4, без автоматической оценки погрешности: для быстрых изменений сил уменьшайте шаг и сравнивайте результат. Высота пользовательского полёта оценивается по 601 отсчёту.
- Не все модели приземляются. В таком случае интерфейс явно показывает ограниченный расчётный интервал; его дальность и время не следует трактовать как характеристики завершённого полёта.
- Выражение до 256 символов и 128 узлов; силы до 10¹⁰ Н; в пользовательском RK4 координаты и скорости до 10⁸, в аналитическом решении — до 10¹⁴. Недопустимые значения прерывают расчёт. Это также ограничивает вычислительную нагрузку.
- Кривые разных запусков сохраняют временной порядок, в том числе при немонотонной оси X. В графиках для произвольной оси X выбор времени соответствует ближайшему по X отсчёту текущего запуска; если X не монотонен, соответствие неоднозначно. Для однозначной перемотки используйте время по X или таблицу.
- Экспорт графика — SVG; PNG пока не реализован. CSV содержит текущий запуск и выбранный шаг таблицы (не более 5001 строки).
- Силовые слои показывают стандартные `mg` и `-k(v-u)`; произвольные силы редактора отражаются результирующим ускорением, без автоматического разложения на именованные силы.
- Разворот занимает окно приложения. На телефоне ширина панелей фиксирована; менять её можно на компьютере. При большом количестве приборов/параметров панели прокручиваются.

Исходные изображения `Images/mathlab_*_review.png` сохранены и использованы только как визуальные ориентиры. Зависимостей от MathLab нет.

## PhysicsLab 1.1

Безопасные пределы задаются в `src/physics/limits.ts` и проверяются движком независимо от UI:

| Параметр | Абсолютные границы |
| --- | --- |
| Скорость | 0–10 000 м/с |
| Угол | −90…180° |
| Высота | 0–1 000 000 м |
| X запуска | ±1 000 000 м |
| Масса | 0,001–1 000 000 кг |
| Гравитация | 0,0001–200 м/с² |
| Линейное сопротивление | 0–100 000 кг/с |
| Ветер по каждой оси | ±5000 м/с |

Диапазон ползунка можно расширить в «Диапазон и шаг». При изменении границ автоматический шаг даёт около 200–500 положений. Введённый вручную шаг сохраняется. Точный ввод не округляется к шагу. Значение за пределами текущего ползунка автоматически расширяет его диапазон; абсолютные пределы остаются обязательными.

Статические кривые Recharts отделены от курсоров (до 30 обновлений/с). Сцена следует `requestAnimationFrame`; видимые задержки кадров учитываются полностью, скрытая вкладка приостанавливает отсчёт реального времени. Обычное колесо над аналитикой прокручивает страницу, `Alt + колесо` и кнопки ± меняют масштаб графика.

Подробности, результаты замеров и ограничения: [отчёт PhysicsLab 1.1](docs/physicslab-1.1.md). Для повторения инструментальных замеров сначала запустите Vite, затем `node scripts/benchmark.mjs` (опциональный аргумент — путь к JSON). Можно задать `BENCHMARK_URL` и `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
